# Mora

Mora is a sovereign, self-hosted replacement for Jira Data Center.
It runs on your own infrastructure, so your data stays under your control.

Atlassian ends support for Jira Data Center on 28 March 2029.
Mora gives enterprises in regulated sectors a way to stay on-premise.

- Website: https://mora.io
- Jira Data Center alternative: https://mora.io/jira-alternative
- Migration: https://mora.io/migration
- Contact: hello@mora.io

Mora is commercial software made by Mora Software GmbH, Vienna.
The repositories here contain public documentation and examples.
